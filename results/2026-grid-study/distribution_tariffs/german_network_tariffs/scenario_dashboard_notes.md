# Scenario dashboard columns

Generated by `scripts/eurelectric/grid_study_scenario_dashboard.py`.

## Geography

`n.objective` is **Europe-wide** whole-sector cost (expanded capex + opex).
Physical `de_*` columns are **Germany** (nodes `DE2 0/1/2`).

Installed / sunk annuity is **not** in the objective. Do not use
`n.statistics.system_cost()` for Δ vs Build.

## Cost and investment

| Column | Meaning |
|---|---|
| `system_cost_bn_eur_per_yr` | EU `n.objective` / 1e9 |
| `system_cost_eur_per_mwh` | Objective / EU electricity generation (not German end-use) |
| `dso_investment_vs_build_bn` | German **new** DSO overnight CAPEX vs Build (`ΔP × 667901.6 €/MW`) |
| `dso_annualised_cost_vs_build_bn` | German DSO stock annuity vs Build (not in the objective) |
| `tso_investment_vs_build_bn` | German TSO **new** annualised cost vs Build |
| `eu_dso_investment_vs_build_bn` | EU DSO new annualised (in the objective) vs Build |
| `eu_tso_investment_vs_build_bn` | EU TSO AC+DC new annualised vs Build |

85/75/65/50% are **EU-wide DSO budget labels**. German realised DSO stock vs
Build is endogenous (not equal to those percentages).

## Physical

- End-use = conventional LV + industry + agriculture + data centres + HP + resistive heating + BEV. Not HV→LV alone; not gross + electrolysis.
- `de_shedding_hours` = snapshot-weighted hours with German LV load-shedding **> 1 MW** (solver crumbs ignored). EV-battery shedding is `de_ev_shedding_twh`, not in those hours.
- CO₂ = `co2 atmosphere` store `e_final − e_initial` (Mt).
- Curtailment = unused VRE potential only (`solar`, `solar rooftop`, `onwind`, `offwind-*`). Do not use `n.statistics.curtailment()`.

## Decomposition

`system_cost_decomposition_vs_build.csv` splits EU `expanded_capex + opex`
by asset bucket. Shares are of that scenario-year’s Δ vs Build.
`residual_vs_objective` is the (≈0) gap to `n.objective`.
