# Endogenous vs Exogenous Data in PyPSA-EUr

This document categorizes data in PyPSA-EUr into:
- **Endogenous data**: Calculated/generated within the code flow and not directly changeable
- **Exogenous data**: Input from external data sources or configuration files

---

## ENDOGENOUS DATA (Calculated/Generated - Not Directly Changeable)

These are data that are computed, derived, or generated during the PyPSA-EUr workflow and are not directly modifiable by users (except through changing inputs or configuration).

### Network Structure & Topology
- **Network buses, lines, links, transformers**: Derived from OSM/TYNDP/ENTSOE data through processing
- **Voronoi cells**: Calculated for substations in `base_network.py`
- **Clustered network regions**: Generated through k-means clustering in `cluster_network.py`
- **Simplified network topology**: Created by `simplify_network.py` (380kV equivalent network)
- **Network line ratings**: Calculated from weather data in `build_line_rating.py` (temperature-dependent resistance)
- **Station seeds and merged buses**: Generated during network building process

### Renewable Energy Profiles & Potentials
- **Renewable generation profiles** (`profile_{technology}.nc`): Calculated from weather data (ERA5/SARAH) using atlite
  - Wind power profiles (onshore, offshore-AC, offshore-DC, floating)
  - Solar PV profiles
  - Solar thermal profiles
- **Capacity factors**: Computed from weather data for each grid cell
- **Installable capacity potentials** (`p_nom_max`): Calculated from land-use constraints and availability matrices
- **Resource classes/bins**: Generated by dividing potentials based on average capacity factors
- **Average distances**: Calculated distance from generators to grid buses
- **Availability matrices**: Computed from land-use data and constraints (CORINE, protected areas, etc.)
- **Hydroelectric profiles**: Generated from runoff data in `build_hydro_profiles.py`

### Energy Demand & Load Profiles
- **Electricity demand profiles**: Generated from synthetic demand or historical patterns
- **Heat demand profiles**: Calculated from HDD (Heating Degree Days) and temperature data
- **Industrial load profiles**: Generated from FfE profiles and industrial site data
- **Transport demand profiles**: Calculated from mobility data and vehicle stock
- **DSM (Demand Side Management) profiles**: Generated for flexible demand
- **Heat DSM profiles**: Calculated for heat demand flexibility
- **Avail profiles**: Generated availability profiles for various technologies

**Note on Future Demand Projections**: Energy demand for future planning horizons (2030, 2040, 2050) is typically based on the base year specified in `energy.energy_totals_year` (default: 2019). The demand is NOT automatically scaled to future years. However:
- **Industrial production** is projected using recycling rates and technology fractions (see `build_industrial_production_per_country_tomorrow.py`)
- **Heat demand** can be approximated for different weather years using HDD regression (see `build_heat_totals.py`)
- **Industrial electricity demand** uses future production data when temporal profiles are enabled

### Technology Performance & Efficiency
- **COP (Coefficient of Performance) profiles**: Calculated for heat pumps from temperature data
- **PTES (Pit Thermal Energy Storage) profiles**: Generated for district heating systems
- **Direct heat source utilisation profiles**: Calculated from temperature and demand data
- **Line resistance**: Calculated from temperature-dependent formulas
- **Transmission losses**: Computed during network solving

### Network Optimization Results
- **Optimal capacities** (`p_nom_opt`): Determined by optimization solver
- **Optimal dispatch** (`p`, `p0`, `p1`): Calculated generation/dispatch per technology
- **Optimal storage levels** (`state_of_charge`): Determined by optimization
- **Optimal flows** (`p0`, `p1` for lines/links): Calculated transmission flows
- **Shadow prices/duals**: Computed by optimization solver (LMPs, congestion prices)
- **Objective value**: Total system cost from optimization
- **Energy balances**: Calculated nodal energy balance per carrier
- **Curtailment**: Calculated renewable energy curtailment
- **Market values**: Computed from dispatch and prices

### Summary Statistics (Post-Processing)
- **Nodal capacities**: Aggregated capacity statistics per node
- **Costs**: Total system costs (investment, operational, fuel)
- **Energy statistics**: Total energy generation/consumption per carrier
- **Price statistics**: Electricity price statistics (mean, min, max, etc.)
- **CO2 emissions**: Calculated from fuel consumption and emission factors
- **Metrics**: System-level metrics (renewable share, capacity factors, etc.)
- **Supply/Supply energy**: Energy supply statistics
- **Weighted prices**: Population-weighted electricity prices

### Spatial Processing
- **Admin shapes**: Generated administrative boundaries from NUTS data
- **Onshore/offshore regions**: Calculated from geographic boundaries
- **Distance regions**: Computed for renewable resource allocation
- **Class regions**: Generated regions by resource quality classes
- **Population-weighted energy totals**: Calculated from population distribution
- **Biomass transport costs**: Computed from spatial distances and potentials

### Sector-Specific Calculations
- **Retrofit costs**: Calculated building retrofit costs (if endogenous)
- **Floor area**: Computed building floor area from population and statistics
- **CO2 sequestration potential**: Calculated from geological data
- **Biomass potentials**: Computed from ENSPRESO data and land constraints
- **Geothermal potentials**: Calculated from geological surveys
- **Aquifer storage potentials**: Computed from BGR aquifer data
- **H2 salt cavern potentials**: Calculated from geological data
- **Solar rooftop potentials**: Computed from building data and solar radiation

### Temporal Processing
- **Snapshot weightings**: Calculated temporal weightings for representative periods
- **Temporal clustering**: Generated representative snapshots from full time series
- **Time series aggregation**: Computed aggregated profiles for different resolutions

## EXOGENOUS DATA (Input from External Sources or Configuration)

These are data that come from external files, databases, or configuration settings and can be modified by users.

### Configuration Parameters (config/config.default.yaml)
- **Countries**: List of countries to include
- **Snapshots**: Time period (start, end, inclusive)
- **Clusters**: Number of network clusters
- **Planning horizons**: Years for optimization (e.g., 2030, 2050)
- **Scenario options** (`opts`, `sector_opts`): Technology and sector options
- **Foresight mode**: overnight, perfect, or myopic
- **CO2 budget**: Annual CO2 emission limits per year
- **Electricity settings**:
  - Base network source (OSM, TYNDP, ENTSOEGridKit)
  - Voltage levels
  - Gas/CO2 limits
  - Operational reserve parameters
  - Max storage hours
  - Extendable carriers
  - Power plant filters
  - Conventional/renewable carrier lists
- **Renewable settings**: Technology-specific parameters (cutout selection, resource classes, etc.)
- **Cost parameters**: Year, discount rate, fill values, custom cost files
- **Clustering settings**: Algorithm, features, aggregation strategies
- **Sector settings**: All sector-specific parameters (heating, transport, industry, etc.)
- **Solving options**: Solver name, options, constraints, etc.
- **Data source versions**: Which version of each dataset to use

### Weather Data (External Files)
- **ERA5 reanalysis data**: Wind speeds, solar radiation, temperature, runoff, HDD
- **SARAH-3 satellite data**: Surface solar radiation (direct, diffuse, TOA)
- **HERA data**: River discharge for surface water heat potential
- **Seawater temperature**: Ocean temperature data
- **Cutout files**: Pre-processed weather data files (`.nc` format)

### Geographic & Administrative Data
- **NUTS regions** (2013, 2021): Administrative boundaries from Eurostat
- **NUTS3 population**: Population data from Eurostat (`nama_10r_3popgdp`)
- **LAU regions**: Local Administrative Units boundaries
- **Country shapes**: Geographic boundaries
- **EEZ (Exclusive Economic Zones)**: Maritime boundaries
- **OSM boundaries**: Administrative boundaries from OpenStreetMap
- **Offshore shapes**: Offshore area definitions

### Land Use & Land Cover
- **CORINE Land Cover**: Land cover classification from Copernicus
- **Copernicus Global Land Cover**: Global land cover data
- **LUISA Base Map**: Land use data from JRC
- **Natura 2000**: Protected area boundaries
- **WDPA/WDPA Marine**: Protected areas (terrestrial and marine)

### Energy Infrastructure Data
- **OSM network data**: Buses, lines, links, transformers, converters (from OSM or archive)
- **TYNDP network**: Reference grid from ENTSO-E
- **ENTSOEGridKit**: Network data from ENTSO-E GridKit
- **SciGrid gas infrastructure**: Gas pipelines, storage, border points
- **Power plants database**: Existing plant locations, capacities, technologies
- **Attributed ports**: Port locations and attributes

### Energy Demand & Consumption Data
- **JRC IDEES**: Industrial production, energy consumption by sector, heat demand, transport energy
  - **Base year**: Typically 2015 or 2021 data
  - **Used for**: Historical energy consumption patterns, sectoral breakdowns
  - **Future projection**: Data from base year is used for future planning horizons (not automatically scaled)
- **Eurostat Energy Balances**: Energy balances for non-EU28 countries
  - **Used for**: Rescaling IDEES data to match Eurostat totals, filling gaps for non-IDEES countries
  - **Rescaling method**: Ratio of Eurostat data for target year vs. 2021 is applied to IDEES data
- **Eurostat Household Balances** (`nrg_d_hhq`): Household energy consumption by end-use
- **Hotmaps Industrial Database**: Spatial distribution of industrial sites
- **FfE Industrial Load Profiles**: Temporal electricity load profiles for industries
- **Mobility profiles**: Vehicle mobility patterns and transport demand
- **Synthetic electricity demand**: Pre-generated demand profiles (if used)

**Configuration for Demand Year**:
- `energy.energy_totals_year` (default: 2019): Specifies which year's energy totals to use
- This year's data is used for all planning horizons unless sector-specific projections are applied

### Population & Economic Data
- **WorldPop Population Count**: High-resolution population raster (1km)
- **GDP per capita**: Economic data for demand allocation
- **World Bank Urban Population**: Urban population statistics
- **JRC ARDECO**: GDP and population at administrative level
- **BFS data** (Switzerland): Road vehicle stock, GDP, population

### Renewable Resource Data
- **ENSPRESO Biomass**: Biomass potential data
- **H2 Salt Caverns**: Hydrogen storage potential locations
- **Aquifer Data (BGR)**: Aquifer locations and properties
- **Geothermal Heat Utilisation Potentials**: Geothermal resource data
- **District Heating Areas**: Existing district heating network boundaries

### Technology Cost Data
- **Technology costs** (from technology-data repository): Capital costs, O&M costs, fuel costs, lifetimes, efficiencies
- **Custom cost files**: User-defined cost overrides (`data/custom_costs.csv`)
- **Cost adjustments**: Configuration-based cost multipliers

### Environmental & Climate Data
- **GHG Emissions (UNFCCC)**: Historical greenhouse gas emissions
- **Country Runoff**: Pre-calculated runoff per country (from ERA5)
- **Country HDD**: Pre-calculated Heating Degree Days per country (from ERA5)
- **CO2Stop**: CO2 storage potential data

### Maritime & Shipping Data
- **Ship Raster**: Shipping routes and density
- **GEBCO**: Ocean bathymetry for offshore wind deployment

### Industry-Specific Data
- **GEM Europe Gas Tracker**: Gas infrastructure data
- **GEM Global Steel Plant Tracker**: Steel plant locations and capacities
- **Nitrogen Statistics**: Fertilizer production data

### Validation Data
- **Monthly CO2 Prices (EEX)**: Historical CO2 price data
- **Monthly Fuel Prices**: Historical fuel price data

### Data Versioning
- **data/versions.csv**: Dataset version information, sources, URLs, tags

## Notes

1. **Boundary Cases**:
   - Some data can be both exogenous (input) and then processed to become endogenous (e.g., weather data → renewable profiles)
   - Configuration parameters are exogenous but determine how endogenous data is calculated
   - Pre-calculated data (like country HDD) is exogenous even though it could be calculated from raw weather data

2. **Modifiability**:
   - Endogenous data can be indirectly modified by changing exogenous inputs or configuration
   - Exogenous data can be directly modified by:
     - Changing configuration files
     - Replacing input data files
     - Using different data source versions

3. **Data Flow**:
   - Exogenous data → Processing scripts → Endogenous data → Optimization → Results (also endogenous)

4. **Customization**:
   - Users can override many exogenous parameters through configuration
   - Custom cost files allow modification of technology costs
   - Custom extra functionality allows modification of optimization constraints
